# github-actions-demo

Demorepo för GitHub-spåret i AWS-kursen (MOV25). Repot visar GitHub Actions på ett litet, fristående exempel:

- `index.html`, en enkel webbsida för det fiktiva bolaget Novatrix
- `scripts/`, två små bash-skript
- `templates/demo-vpc.yaml`, en minimal CloudFormation-template med en tom VPC
- `.github/workflows/`, workflows som läggs till steg för steg under kursens veckor

Repot innehåller inga lösningar på kursens uppgifter. Idéerna här får du gärna föra över till ditt eget repo.
